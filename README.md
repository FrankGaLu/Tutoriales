# Tutoriales — FrankGaLu

Colección de tutoriales técnicos mantenidos por Dr. Francesco Garcia-Luna.

Contenido:

- ROS2 (es/en): ROS2 jazzy basic tutorial, publisher/subscriber examples, URDF and RVIZ2 notes.
- MQTT (es/en): Mosquitto setup and paho-mqtt examples (Python snippets).
- Bash (es/en): Terminal basics and safe usage notes.
- Graphviz (es/en): DOT language examples and how to render graphs.

Objetivo: mejorar la calidad de los tutoriales (ortografía, consistencia, ejemplos ejecutables) y proporcionar instrucciones claras para reproducir los ejemplos.

Cómo contribuir:

1. Crea una rama a partir de `main`.
2. Haz cambios pequeños y commit con mensajes descriptivos.
3. Ejecuta validaciones locales: revisar snippets Python con `python3 -m py_compile`.
4. Abre un Pull Request desde tu rama hacia `main` explicando los cambios.

Notas para mantenedores:
- Los snippets Python han sido validados por sintaxis con `py_compile`.
- Añade instrucciones para instalar dependencias cuando un tutorial incluya código ejecutable.
